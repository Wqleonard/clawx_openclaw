# BoomClaw 项目评估报告

---

## 一、项目是什么

BoomClaw 是一款**桌面端 AI 助手应用**，支持 Windows 和 macOS。

用户可以在桌面上直接与 AI 对话、执行终端命令、管理 AI Agent、使用技能市场——同时接入爆文猫账号体系和 AI 模型，形成一套完整的企业级 AI 工作台。

---

## 二、初始构建

没有从零开发，在成熟的开源项目 **ClawX**（基于 OpenClaw AI Runtime）基础上进行二次开发。

**这意味着：**
- 桌面壳、打包发布、自动更新、终端能力、AI Agent 管理等核心基础设施**直接复用**，不重复造轮子
- 工作聚焦在**接入爆文猫账号体系、 AI 模型、业务接口**，以及产品体验优化，参照autoclaw方向

---

## 三、技术底座（已有能力）

以下能力来自 ClawX / OpenClaw，**已完整保留，开箱即用，可部分剔除**：

| 能力 | 说明 |
|------|------|
| 桌面壳 | Electron 框架，支持 Windows / macOS 打包发布 |
| AI 对话 | 流式 Markdown 渲染，支持思考过程展示、工具调用卡片 |
| 终端能力 | 内置 PTY 终端，AI 可直接执行系统命令 |
| Agent 管理 | 多 Agent 配置、切换、管理 |
| 技能市场 | 内置技能安装与管理（OpenClaw 生态） |
| 自动更新 | 应用内静默更新，支持阿里云 OSS / GitHub 双渠道 |
| 多语言 | 中文 / 英文 / 日文界面 |

## 四、已完成的扩展

### 1. 登录与用户系统

- 接入账号体系（`baowenmao.com`），通过 iframe + ticket 机制完成登录
- 登录状态持久化，支持 token 自动注入到所有 API 请求
- 完整的路由守卫：未登录自动跳转登录页，登录后进入主界面
- 支持退出登录，清除本地凭证

### 2. 业务 API 客户端

- 封装统一的 HTTP 客户端，自动携带登录 token
- 支持多环境切换（开发 / 测试 / 生产），一行命令切换
- 支持流式接口（为后续接入爆文猫 AI 模型做好准备）

### 3. 富文本编辑器

- 聊天页内嵌 Markdown 富文本编辑器（基于 Tiptap v3）
- 三栏布局：侧边栏 | 编辑器 | 聊天区，编辑器宽度可拖拽调整
- AI 回复内容支持**一键导入编辑器**，方便用户整理 AI 输出的内容
- 编辑器支持标题、加粗、斜体、列表、代码块等常用格式
