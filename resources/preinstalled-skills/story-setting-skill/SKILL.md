# 故事背景设定技能

---

## 故事设定文件格式规范（设定/故事设定.md）

故事设定存储在 `.{你的工作区路径}/设定/` 文件夹。该文件夹用于存储所有故事相关设定，永久存在，不得删除，名称只能是 `.{你的工作区路径}/设定/`。

故事设定文件路径固定为 `.{你的工作区路径}/设定/故事设定.md`，用于存储：文章标题、故事简介、主要事件、世界观设定、其他设定、文本类型。

文件格式为 Markdown（`.md`），内容结构必须严格遵守：

```md
## 文章标题
[文章标题内容]

## 故事简介
[整本小说的故事梗概，将整个小说用一句话说完。字数少于一行。]

## 主要事件
[故事主要事件的简要描述，单个事件字数少于一行，每个事件应该对应多个章节（用户必须提供）]

## 世界观设定
[世界观设定（可由AI补全）]

## 其他设定
[其他设定（可由AI补全）]

## 文本类型
[文本类型]
```

## 工作流程

### Step 1：读取已有故事设定（如有）

```
read_file(".{你的工作区路径}/设定/故事设定.md")
```

若文件不存在，直接进入 Step 2。

### Step 2：使用思考工具分析信息是否充分

在正式写文件前，先判断用户输入是否足以支撑完整故事设定：

- 若信息充分：进入 Step 3。
- 若信息不足或缺乏灵感：必须先补充信息后再写文件。

当信息不足时，必须先调用：
1. 联网搜索工具（用于获取题材素材、背景参考、同类元素）

补充完成后，整理为可执行设定要点，再进入 Step 3。

### Step 3：生成并写入 `.{你的工作区路径}/设定/故事设定.md`

按“故事设定文件格式规范”生成完整内容，并写入：

```
write_file("./设定/故事设定.md", ...)
```

若为编辑场景，则在保留已有合理内容的基础上按用户要求增改，避免无关重写。

## 质量要求

- 世界观设定必须**内部自洽**：不同文件中的信息不得矛盾
- 每个核心设定都要有**意义**：能影响人物行为或推动情节
- 保持**扩展空间**：不要把世界设定得过于完整，留有后续展开的余地
- 避免**过度设定**：聚焦服务于故事的核心内容，无关细节简略处理
