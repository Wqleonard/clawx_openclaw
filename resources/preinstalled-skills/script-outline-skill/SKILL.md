# 集纲技能

---

## 集数与章节的关系

**短剧集数不按小说章节数确定**。小说剧情拆解（/剧情.md）完全按章节数，一章一拆；集纲的**总集数**应参考原文字数与小说类型，遵循以下规律：

| 小说类型   | 原文字数   | 短剧集数   | 改编比例     |
| ---------- | ---------- | ---------- | ------------ |
| 短篇小说   | 1–3 万字   | 20–30 集   | 大幅扩写     |
| 中篇小说   | 10–30 万字 | 80–100 集  | 适度扩写/正常改编 |
| 长篇小说   | 50–100 万字 | 80–120 集 | 正常改编或压缩 |
| 超长篇网文 | 100 万字+  | 80–100 集  | 大幅压缩     |

用户未指定集数时，可根据 `.{你的工作区路径}/剧情.md` 或小说原文字数及上表给出推荐集数；若 `.{你的工作区路径}/设定/故事设定.md` 中已有「集纲建议」或推荐集数，可与之结合使用。

---

## 集纲文件格式规范（.{你的工作区路径}/集纲.md）

集纲路径固定为 `.{你的工作区路径}/集纲.md`。格式为 Markdown（`.md`），内容结构必须严格遵守：

```md
【1-X（起）】
第1集：标题（5-8字）
故事梗概（100字左右）

第2集：标题（5-8字）
故事梗概（100字左右）

......

【X-X（承）】
......

第N集：标题（5-8字）
故事梗概（100字左右）
```

- 每集须有「第N集：标题」与对应故事梗概；剧情体现人物关系、核心冲突与情节转折，无情绪/心理/对话等冗余描写。
- 集纲须包含起承转合，前后逻辑连贯。可按 `.{你的工作区路径}/设定/故事设定.md` 中的「集纲建议」（如 `1-10(起)`、`11-30(承)`、`31-50(转)`、`51-60(合)`）进行生成，每批只写该部分对应集数。

## 工作流程

### Step 1：读取必备文件（如有）

```
read_file(".{你的工作区路径}/剧情.md")
read_file(".{你的工作区路径}/设定/剧本选题.md")
read_file(".{你的工作区路径}/设定/故事设定.md")
read_file(".{你的工作区路径}/设定/角色设定.md")
```

若 task 中已含脑洞、角色、当前小说剧情或已有集纲，以 task 为准。

### Step 2：生成并写入 `.{你的工作区路径}/集纲.md`

```
write_file(".{你的工作区路径}/集纲.md", ...)
```

若为编辑场景，则在保留已有合理内容的基础上按用户要求增改。

### Step 3：写后自检

- 本批集数、每集标题与梗概齐全，人物关系、核心冲突与情节转折清晰，无多余情绪/心理/对话描写。
- 若为分批：本批与已有集纲集数连续，起承转合与逻辑连贯。

---

## 质量要求

- 集纲须完整叙述起承转合，前后逻辑连贯；剧情聚焦人物关系、核心冲突与情节转折，不出现情绪、描写、心理活动、对话等冗余内容。
- 与剧情、剧本选题、故事设定、角色设定一致，不擅自引入冲突设定；分批时本批须与已有集纲及前后部分在情节与人物动机上衔接一致。
