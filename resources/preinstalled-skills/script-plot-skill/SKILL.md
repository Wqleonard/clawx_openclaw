# 剧情技能

---

## 剧情文件格式规范（剧情.md）

剧情文件名只能是 `/剧情.md`，并存储在根目录下。

**重要**：小说剧情拆解**完全根据章节数**进行，一章对应一条章目，不按短剧集数合并或拆分。短剧集数在集纲阶段根据原文字数与小说类型另行确定（见 script-outline-skill 中的集数参考规律）。

文件格式为 Markdown（`.md`），内容结构必须严格遵守：

```md
# 第N章 章节标题（5-8字）

导语：（100字左右）

情节1：（30字左右）

......

情节N：（30字左右）

......
```

---

## 工作流程

### Step 1：读取已有小说原文（如有）

```
url_content_parser_tool("...")
```

或
```
read_file("小说原文.md")
```

### Step 2：生成并写入 `/剧情.md`

按“故事设定文件格式规范”生成完整内容，并写入：

```
write_file("/剧情.md", ...)
```

若为编辑场景，则在保留已有合理内容的基础上按用户要求增改，避免无关重写。

### Step 3：写后自检

- 剧情.md 中每章均包含「# 第N章 标题」、导语、多个情节，格式统一。
- 导语与各情节点字数大致符合规范，逻辑连贯。

---

## 质量要求

- 剧情拆解结果须忠实于小说原文，不篡改情节走向。
- 章节顺序与原文一致，不遗漏、不合并用户未要求的章节。
- **小说剧情拆解完全根据章节数**：一章对应 `/剧情.md` 中的一条章目（# 第N章 …），不按短剧集数合并或拆分；短剧集数由后续集纲阶段根据原文字数/类型另行确定。
- **导语**：每章导语控制在 100 字左右，概括本章核心冲突或转折，语言凝练、不剧透后续情节。
- **剧情**：每个情节点控制在 30 字左右，表述具体可演、时间顺序清晰，不写抽象概括或重复内容。
