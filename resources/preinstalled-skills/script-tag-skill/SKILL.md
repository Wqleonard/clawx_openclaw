# 剧本选题技能

---

## 剧本选题文件格式规范（/设定/剧本选题.md）

文件名只能是 `/设定/剧本选题.md`。格式为 Markdown（`.md`），内容结构必须严格遵守：

```md
## 题材
[题材，一行]

## 情节
[情节标签 1–3 个，一行]

## 背景
[故事背景，一行]

## 故事受众
[女频/男频等，一行]

## 推荐集数
[不少于40集，一行]

## 故事梗概
[多段叙述，人物关系、核心冲突、关键情节点与结局；可选用（一卡）（二卡）等节奏标记]
```

---

## 工作流程

### Step 1：读取剧情（如有）

```
read_file("/剧情.md")
```

### Step 2：生成并写入 `/设定/剧本选题.md`

按“剧本选题文件格式规范”生成完整内容，并写入：

```
write_file("/设定/剧本选题.md", ...)
```

若为编辑场景，则在保留已有合理内容的基础上按用户要求增改，避免无关重写。

### Step 3：写后自检

- /设定/剧本选题.md 包含六个 ## 小节，前五节各一行，故事梗概为多段叙述。
- 题材、情节、背景、故事受众、推荐集数贴合剧情，故事梗概逻辑清晰、为后续改编提供依据。

---

## 质量要求

- 题材、情节、背景、故事受众、推荐集数须贴合剧情，不臆造。
- 故事梗概须概括全书主要情节、人物关系与核心冲突，不少于500字，语言精炼。
