# 角色设定技能

---

## 角色设定文件格式规范（/设定/角色设定.md）

文件名只能是 `.{你的工作区路径}/设定/角色设定.md`。格式为 Markdown（`.md`），内容结构必须严格遵守：每个角色为一个二级标题 `## 角色姓名`，其下为定位、年龄、人物标签、人物小传四项。

```md
## 角色姓名
- **定位**：[男主/女主/反派等]
- **年龄**：[XX岁]
- **人物标签**：[20字以内，多个按顿号分割]
- **人物小传**：[约100字，可含核心价值观、动机、创伤、人生哲学等]

## 角色姓名
- **定位**：...
- **年龄**：...
- **人物标签**：...
- **人物小传**：...
```

---

## 工作流程

### Step 1：读取必备文件（如有）

```
read_file(".{你的工作区路径}/剧情.md")
read_file(".{你的工作区路径}/设定/剧本选题.md")
read_file(".{你的工作区路径}/设定/故事设定.md")
```

### Step 2：生成并写入 `.{你的工作区路径}/设定/角色设定.md`

根据剧情或用户描述/脑洞抽取或创作角色。按“角色设定文件格式规范”生成每个角色的定位、年龄、人物标签、人物小传，并写入：

```
write_file(".{你的工作区路径}/设定/角色设定.md", ...)
```

若为编辑场景，则在保留已有合理内容的基础上按用户要求增改，不擅自删除未要求修改的角色。

### Step 3：写后自检

- /设定/角色设定.md 中每个角色均包含 ## 角色姓名 及四项（定位、年龄、人物标签、人物小传）。
- 角色姓名为具体姓名，非泛称；人物标签与人物小传与剧情/设定一致。

---

## 质量要求

- 角色姓名必须具体到姓名，不使用「主角」「反派」等泛称。
- 人物标签与人物小传需与剧情/故事设定一致，不臆造冲突设定。
- 人物小传需对写作有指导价值，突出动机与特质。
