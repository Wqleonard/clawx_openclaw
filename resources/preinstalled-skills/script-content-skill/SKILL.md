# 剧本正文技能

---

## 剧本正文文件格式规范（/剧本/第1集.md、/剧本/第2集.md …）

剧本正文存储在 `/剧本/` 文件夹下。该文件夹用于存储短剧剧本相关产出，名称只能是 `/剧本/`。

剧本正文文件必须命名为：

- `/剧本/第1集.md`
- `/剧本/第2集.md`
- `/剧本/第N集.md`
- ...

格式要求：

1. 文件为 Markdown（`.md`），内容为该集的完整剧本正文。
2. 每集时长约 1 分 30 秒，剧本字数 800–1200 字；对话占比 70% 以上。
3. 每集须有强情绪爆点，结尾须留钩子（悬念/反转/冲突升级）；每集可有 1–3 个场景。

**结构规范：**

- **集-幕**：以 X-X 表示（如 1-1 表示第 1 集第 1 幕）。
- **时间**：日（白天）/ 夜（夜晚）。
- **地点**：内（地点）/ 外（地点） + 简单描述（如：内 林家别墅 - 卧室）。
- **人物**：开头列出本场出场人物，格式为「人物：姓名1（核心特征）、姓名2（核心特征）」。
- **场景与动作**：使用 △ 标注场景描述和动作描述；极简场景（3–5 字关键视觉信息），禁止大段环境描写、心理活动叙述、背景铺垫。
- **对话**：格式为「人物名：（情绪/状态描述）对话内容」，情绪关键词 2–4 字、可表演（如：强忍泪水、讥讽冷笑）。

**节奏参考（不直接写进正文）：**

- 前 15 秒：强冲突开场
- 15–45 秒：冲突升级
- 45–75 秒：情绪爆点
- 75–90 秒：钩子

**禁止：** OS/内心独白（须转化为动作或台词）、单场描写超过一行、平淡过渡、一集内解决全部冲突。

## 工作流程

### Step 1：读取必备文件（如有）

```
read_file("/集纲.md")
read_file("/设定/角色设定.md")
read_file("/剧本/第N集.md")     # 若为改写/续写本集
read_file("/剧本/第N-1集.md")   # 若需承接上一集
```

若 task 中已含集纲片段、角色信息或已有剧情，以 task 为准；有独立文件时须读取。

### Step 2：生成并写入 `/剧本/第N集.md`

- 严格遵循 `/集纲.md` 中本集的故事梗概与节奏，与 `/设定/角色设定.md` 保持一致。
- 按本 SKILL 的格式规范书写集-幕、时间、地点、人物、△ 场景与动作、对话格式；每集有情绪爆点与结尾钩子。
- 使用：

```
write_file("/剧本/第N集.md", ...)
```

若为编辑场景，则在保留已有合理内容的基础上按用户要求增改。

### Step 3：写后自检

- 集-幕、时间、地点、人物、△ 与对话格式是否符合规范。
- 是否无 OS、无超长场景描写、无平淡过渡，且结尾有钩子。
- 字数与节奏是否在 800–1200 字、约 1 分 30 秒内。

---

## 质量要求

- 剧本正文须可直接用于拍摄参考，不夹杂流程说明或元注释。
- 人物行为与动机需与角色设定一致；对话与动作推动剧情与情绪。
- 语言风格与文风文件（若有）保持一致；每集必须有情绪爆点与结尾钩子。
