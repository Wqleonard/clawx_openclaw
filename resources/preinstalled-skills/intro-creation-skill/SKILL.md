## 导语文件格式规范（./正文/导语.md）

导语文件固定存储在 `./正文/导语.md`。

格式要求：

1. 文件为 Markdown（`.md`），内容使用纯文本表达，不使用表格、代码块或复杂结构。
2. 导语必须非常简洁，避免冗长铺垫导致阅读疲劳。
3. 导语应简洁有力，重点营造悬念或展现故事核心魅力。
4. 导语内容只写导语正文，不额外添加章节标题或说明文字。

## 工作流程

### Step 1：读取设定相关文件

创作前至少读取：

```
read_file("./设定/故事设定.md")
read_file("./设定/角色设定.md")
read_file("./大纲.md")
read_file("./正文/导语.md")   # 如已存在，用于改写
```

### Step 2：判断当前小说类型

先根据用户输入、`./设定/故事设定.md`、`./大纲.md` 判断题材类型（如悬疑、甜文、虐文、爽文、世情、职场、复仇、穿书、重生等）。

### Step 3：读取对应题材的导语写作指南

根据题材，从此skill的 `./intro-creation-skill/导语写作指南` 目录下读取对应指南文件：

```
./intro-creation-skill/导语写作指南/
```

若没有精确匹配，则读取最接近题材的指南，并保持风格一致。

### Step 4：生成并写入导语

将导语写入：

```
write_file("./正文/导语.md", ...)
```

生成要求：

- 内容短小精悍，信息密度高
- 开篇即抓人，优先悬念、冲突、反差、强情绪其一
- 与故事设定和大纲一致，不臆造冲突设定

### Step 5：写后自检

写入后必须检查：

- 是否足够简洁，无冗余背景说明
- 是否具备吸引读者继续阅读的钩子
- 是否与 `./设定/故事设定.md`、`./设定/角色设定.md`、`./大纲.md` 一致

---

## 质量要求

- **短而有力**：优先一句一击中的表达，避免拖沓
- **有明确钩子**：必须给出可持续阅读的问题、危机或情绪悬点
- **风格对齐题材**：导语语气、节奏、意象与题材指南一致
- **禁止剧透结局**：只展示吸引点，不提前泄露核心反转
