# 故事设定技能

---

## 故事设定文件格式规范（/设定/故事设定.md）

文件名只能是 `.{你的工作区路径}/设定/故事设定.md`。格式为 Markdown（`.md`），内容结构必须严格遵守：

```md
## 剧名
[短剧标题，8-15字]

## 核心梗概
[主要情节概括，含人物、冲突、主线，200-300字]

## 故事背景
[时间、地点、社会环境，100-150字]

## 核心亮点
[卖点 1-2 个，100-150字]

## 信息差
[观众与角色、角色间的信息不对称，100-150字]

## 分集建议
[起：1-10集]
[承：10-30集]
[转：31-50集]
[合：50-60集]

```

**两种模式**（由 task 中的用户选择决定）：**原版**——根据小说/章纲概括，不改变情节走向；**改编**——仅参考原文题材/风格，剧情节点、转折、人物关系、核心冲突与结局全部重新创作，与原文无重合。

---

## 工作流程

### Step 1：读取必备文件（如有）

```
read_file(".{你的工作区路径}/剧情.md")
read_file(".{你的工作区路径}/设定/剧本选题.md")
```

### Step 2：生成并写入 `.{你的工作区路径}/设定/故事设定.md`

从 task 中明确：用户选择**原版**还是**改编**；若为改编，提取**改写方向**并严格重写剧情。按“故事设定文件格式规范”生成剧名、核心梗概、故事背景、核心亮点、信息差，并写入：

```
write_file(".{你的工作区路径}/设定/故事设定.md", ...)
```

若为编辑场景，则在保留已有合理内容的基础上按用户要求增改，避免无关重写。

### Step 3：写后自检

- /设定/故事设定.md 包含五个 ## 小节（剧名、核心梗概、故事背景、核心亮点、信息差），各字段字数符合规范。
- 改编模式下不得与原文剧情点重合；原版模式须忠实概括原文。

---

## 质量要求

- 所有字段准确反映「原版」或「改编后」故事核心，符合短剧商业化需求。
- 改编时剧情节点、转折、人物关系、核心冲突与结局须重新创作，与原文无重合。
- 剧名、核心梗概、故事背景、核心亮点、信息差之间逻辑一致。
